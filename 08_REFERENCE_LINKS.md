# Reference Links

These are implementation references, not the product spec.

## HopHacks
The opening-ceremony deck supplied by the user states that:
- only one official track may be chosen,
- the Data Visualization challenge uses Baltimore City open data and an interactive marimo notebook,
- public APIs/libraries/open-source tools and AI coding tools are allowed,
- all coding must be completed during the hackathon window.

## Data-source rule
Before final submission, verify the exact current dataset/service URLs actually used by the code and write them to `docs/DATA_SOURCES.md`.
Do not claim a third-party dataset is Baltimore City open data unless provenance is verified.
